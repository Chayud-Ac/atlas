# M2: API and Data Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the user has chosen inline execution) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `@atlas/api`, an Express 5 API with Entra-style token validation, `GET /api/me`, notes CRUD with audit events, Drizzle migrations in schema `app`, a least-privilege runtime database role, and unit, HTTP and Testcontainers integration tests, all runnable locally with Docker.

**Architecture:**

- **Layers:** `routes → services → repositories`.
- **Repositories** are interfaces. There are Postgres implementations (`pg-*.ts`) and in-memory test doubles (`src/test/`).
- **Writes** go through a `UnitOfWork`, so each change and its audit row commit or roll back together.
- **`createApp(deps)`** builds Express from injected dependencies, so HTTP tests need no database or network.
- **The migration job** (`src/migrate.ts`) is a separate entrypoint in the same package. It:
  - takes a Postgres advisory lock
  - applies Drizzle migrations
  - re-applies an explicit grants allowlist to the runtime role

**Tech stack:** Express 5.3, helmet 8, pino 10 + pino-http 11, jose 6, zod 4, Drizzle ORM 0.45 + drizzle-kit 0.31, pg 8.23 (native ESM), uuid 14 (v7), @azure/identity 4, Vitest 5, Supertest 7, Testcontainers 12 (`postgres:17-alpine`), tsx 4, mock-oauth2-server 6.0.6 (local dev only).

**Spec:** `docs/specs/2026-10-13-atlas-scaffold-design.md`. This milestone covers §6.3 (API token validation), §8 (data), §9 (API) and §14.1–14.2 (tests).

**Deviations from the spec (all deliberate):**

1. **A `Problem` zod schema goes into `@atlas/shared`.** The web app parses API errors in M3, so the error shape is part of the contract.
2. **Problem bodies carry `requestId` now.** `traceId` arrives with OpenTelemetry in M7.
3. **401 responses include `WWW-Authenticate: Bearer`,** as RFC 6750 requires.
4. **Entra `oid` and `tid` are validated with `z.guid()`, not `z.uuid()`.** Entra GUIDs aren't guaranteed to carry RFC 9562 version bits, so the strict check could reject a real user. Our own IDs stay strict `z.uuid()` (UUIDv7).
5. **The mock OIDC server is added to `compose.yaml` now, not in M4,** so the API can be run and tried locally with real signed tokens. Local dev files live in `dev/`.
6. **Drizzle stays on 0.45.x.** 1.0 is still a release candidate (`1.0.0-rc.5`), and we don't build on release candidates.

```ts
import { z } from 'zod';

/** One validation failure, pointing at the offending field. */
export const ProblemFieldError = z.strictObject({
  path: z.string(),
  message: z.string(),
});
export type ProblemFieldError = z.infer<typeof ProblemFieldError>;

/**
 * Error body for every non-2xx API response (RFC 9457, application/problem+json).
 * `requestId` matches the x-request-id response header and the API's log lines.
 * Not strict: RFC 9457 allows extension members, which are ignored.
 */
export const Problem = z.object({
  type: z.string(),
  title: z.string(),
  status: z.int().min(400).max(599),
  detail: z.string().optional(),
  errors: z.array(ProblemFieldError).optional(),
  requestId: z.string().optional(),
});
export type Problem = z.infer<typeof Problem>;
```

```ts
import { z } from 'zod';
import { ROLE_NAME } from './db/grants.js';

type Env = Record<string, string | undefined>;

const ENTRA_ISSUER = /^https:\/\/login\.microsoftonline\.com\/[0-9a-f-]{36}\/v2\.0$/;
const CLOUD_ENVS: ReadonlySet<string> = new Set(['dev', 'uat', 'prod']);

const Common = z.object({
  ATLAS_ENV: z.enum(['local', 'ci', 'dev', 'uat', 'prod']),
  LOG_LEVEL: z.enum(['fatal', 'error', 'warn', 'info', 'debug', 'trace', 'silent']).default('info'),
});

const Api = Common.extend({
  APP_VERSION: z.string().min(1).default('local'),
  PORT: z.coerce.number().int().min(1).max(65_535).default(3000),
  OIDC_ISSUER: z.url(),
  OIDC_AUDIENCE: z.string().min(1),
  OIDC_JWKS_URI: z.url().optional(),
  REQUIRED_SCOPE: z.string().min(1).default('access_as_user'),
}).superRefine((env, ctx) => {
  // Issuer guard (spec §6.3): only local and CI may trust a non-Entra issuer such as the mock.
  if (CLOUD_ENVS.has(env.ATLAS_ENV) && !ENTRA_ISSUER.test(env.OIDC_ISSUER)) {
    ctx.addIssue({
      code: 'custom',
      path: ['OIDC_ISSUER'],
      message: `must be an Entra ID v2.0 issuer when ATLAS_ENV is ${env.ATLAS_ENV}`,
    });
  }
});

const Migrator = Common.extend({
  API_ROLE_NAME: z.string().regex(ROLE_NAME, 'must be a plain role name'),
  API_PRINCIPAL_ID: z.guid().optional(),
});

const Db = z.discriminatedUnion('DB_AUTH', [
  z.object({ DB_AUTH: z.literal('password'), DATABASE_URL: z.string().min(1) }),
  z.object({
    DB_AUTH: z.literal('entra'),
    PGHOST: z.string().min(1),
    PGPORT: z.coerce.number().int().min(1).max(65_535).default(5432),
    PGDATABASE: z.string().min(1),
    PGUSER: z.string().min(1),
    PGSSLMODE: z.enum(['disable', 'require']).default('require'),
    AZURE_CLIENT_ID: z.string().min(1),
  }),
]);

export type AtlasEnv = z.infer<typeof Common>['ATLAS_ENV'];
export type LogLevel = z.infer<typeof Common>['LOG_LEVEL'];

export type DbConfig =
  | { auth: 'password'; url: string }
  | {
      auth: 'entra';
      host: string;
      port: number;

      throw new ConfigError(
        `Invalid configuration:\n✖ DB_AUTH must be "entra" when ATLAS_ENV is ${atlasEnv}\n  → at DB_AUTH`,

    host: db.PGHOST,
    port: db.PGPORT,
    database: db.PGDATABASE,
    user: db.PGUSER,
    ssl: db.PGSSLMODE === 'require',
    clientId: db.AZURE_CLIENT_ID,
  };
```

```ts
import type { Problem, ProblemFieldError } from '@atlas/shared';
import { NotFoundError } from '../errors.js';
import { HttpError } from './http-error.js';

const TITLES: Readonly<Record<number, string>> = {
  400: 'Bad Request',
  401: 'Unauthorized',
  403: 'Forbidden',
  404: 'Not Found',
  413: 'Content Too Large',
  415: 'Unsupported Media Type',
  500: 'Internal Server Error',
  503: 'Service Unavailable',
};

/** Errors from Express's body parser (the http-errors package) that are safe to show. */
interface ExposedHttpError {
  status: number;
  expose: true;
  message: string;
}

function isExposedClientError(err: unknown): err is ExposedHttpError {
  return (
    typeof err === 'object' &&
    err !== null &&
    'status' in err &&
    typeof err.status === 'number' &&
    err.status >= 400 &&
    err.status < 500 &&
    'expose' in err &&
    err.expose === true &&
    'message' in err &&
    typeof err.message === 'string'
  );
}

/** Turns anything thrown during a request into an RFC 9457 problem. Unknown errors reveal nothing. */
export function toProblem(err: unknown): Problem {
  if (err instanceof HttpError) return problem(err.status, err.message, err.errors);
  if (err instanceof NotFoundError) return problem(404, err.message);
  if (isExposedClientError(err)) return problem(err.status, err.message);
  return problem(500, 'An unexpected error occurred.');
}

function problem(status: number, detail: string, errors?: ProblemFieldError[]): Problem {
  return {
    type: 'about:blank',
    title: TITLES[status] ?? 'Error',
    status,
    detail,
    ...(errors ? { errors } : {}),
  };
}
```

```ts
import { randomUUID } from 'node:crypto';
import type { IncomingMessage, ServerResponse } from 'node:http';

const SAFE_REQUEST_ID = /^[A-Za-z0-9._-]{1,128}$/;

/**
 * Request id for logs, problem bodies and audit rows (pino-http `genReqId`).
 * Reuses the caller's x-request-id when it can't forge log lines; otherwise mints one.
 */
export function genReqId(req: IncomingMessage, res: ServerResponse): string {
  const incoming = req.headers['x-request-id'];
  const id =
    typeof incoming === 'string' && SAFE_REQUEST_ID.test(incoming) ? incoming : randomUUID();
  res.setHeader('x-request-id', id);
  return id;
}

/**
 * The id assigned by `genReqId`. pino-http adds `req.id` with a loose type, so narrow it here.
 * The `& { id?: unknown }` keeps this compiling whether or not pino-http's types are loaded.
 */
export function requestIdOf(req: IncomingMessage & { id?: unknown }): string {
  return typeof req.id === 'string' ? req.id : '';
}
```

```ts
import { z } from 'zod';

const OpenIdConfiguration = z.object({ issuer: z.string(), jwks_uri: z.url() });

/** Finds the issuer's signing-key endpoint. Refuses a document that names a different issuer. */
export async function discoverJwksUri(
  issuer: string,
  fetchFn: typeof fetch = fetch,
): Promise<string> {
  const url = `${issuer}/.well-known/openid-configuration`;
  const response = await fetchFn(url);
  if (!response.ok) throw new Error(`OIDC discovery failed: ${url} returned ${response.status}`);
  const config = OpenIdConfiguration.parse(await response.json());
  if (config.issuer !== issuer) {
    throw new Error(`OIDC discovery issuer mismatch: expected ${issuer}, got ${config.issuer}`);
  }
  return config.jwks_uri;
}
```

```ts
/** Last middleware: every error becomes application/problem+json. */
export const errorHandler: ErrorRequestHandler = (err: unknown, req, res, next) => {
  if (res.headersSent) {
    next(err);
    return;
  }
  const problem = toProblem(err);
  if (problem.status >= 500) req.log.error({ err }, 'request failed');
  // RFC 6750: tell the client which authentication scheme to use.
  if (problem.status === 401) res.setHeader('WWW-Authenticate', 'Bearer');
  res
    .status(problem.status)
    .type('application/problem+json')
    .json({ ...problem, requestId: requestIdOf(req) });
```

```ts
import type { RequestHandler } from 'express';
import { HttpError } from '../http/http-error.js';
import type { UserIdentity, UsersRepository } from '../users/user.js';
import type { AccessTokenClaims } from './claims.js';
import type { TokenVerifier } from './token-verifier.js';

export interface AuthenticateOptions {
  verifier: TokenVerifier;
  /** Every endpoint requires this delegated scope (spec §6.3: `access_as_user`). */
  requiredScope: string;
  users: UsersRepository;
}

/** Bearer token → verified claims → scope check → just-in-time user → `req.auth`. */
export function authenticate({
  verifier,
  requiredScope,
  users,
}: AuthenticateOptions): RequestHandler {
  return async (req, _res, next) => {
    const token = bearerToken(req.headers.authorization);
    if (!token) {
      throw new HttpError(401, 'Sign in required: send "Authorization: Bearer <access token>".');
    }
    const claims = await verifyOr401(verifier, token);
    const scopes = claims.scp?.split(' ') ?? [];
    if (!scopes.includes(requiredScope)) {
      throw new HttpError(403, `The access token is missing the "${requiredScope}" scope.`);
    }
    const user = await users.upsertFromIdentity(identityOf(claims));
    req.auth = {
      userId: user.id,
      oid: claims.oid,
      tid: claims.tid,
      roles: claims.roles ?? [],
      name: user.displayName,
      email: user.email,
    };
    next();
  };
}

function bearerToken(header: string | undefined): string | undefined {
  return /^Bearer (\S+)$/i.exec(header ?? '')?.[1];
}

async function verifyOr401(verifier: TokenVerifier, token: string): Promise<AccessTokenClaims> {
  try {
    return await verifier.verify(token);
  } catch {
    throw new HttpError(401, 'The access token is invalid or expired.');
  }
}

function identityOf(claims: AccessTokenClaims): UserIdentity {
  return {
    entraTenantId: claims.tid,
    entraObjectId: claims.oid,
    email: claims.email ?? claims.preferred_username ?? null,
    displayName: claims.name ?? null,
  };
}
```

```ts
import { v7 as uuidv7 } from 'uuid';
import type { AuditEvent, AuditRepository } from '../audit/audit-repository.js';
import type { NoteRecord, NotesRepository } from '../notes/notes-repository.js';
import type { UnitOfWork } from '../unit-of-work.js';
import type { User, UsersRepository } from '../users/user.js';

/** In-memory test doubles for the repositories. Unit tests only; Postgres is tested separately. */
export function createInMemoryStore() {
  const users = new Map<string, User>();
  const notes: NoteRecord[] = [];
  const auditEvents: AuditEvent[] = [];

  const usersRepository: UsersRepository = {
    upsertFromIdentity(identity) {
      const key = `${identity.entraTenantId}/${identity.entraObjectId}`;
      const user: User = { id: users.get(key)?.id ?? uuidv7(), ...identity };
      users.set(key, user);
      return Promise.resolve(user);
    },
  };

  const notesRepository: NotesRepository = {
    listByOwner(ownerId) {
      const owned = notes.filter((note) => note.ownerId === ownerId);
      // Same order as Postgres: created_at DESC, id DESC (UUIDv7 is time-ordered).
      owned.sort(
        (a, b) => b.createdAt.getTime() - a.createdAt.getTime() || b.id.localeCompare(a.id),
      );
      return Promise.resolve(owned);
    },
    create(ownerId, input: CreateNoteInput) {
      const now = new Date();
      const note: NoteRecord = { id: uuidv7(), ownerId, ...input, createdAt: now, updatedAt: now };
      notes.push(note);
      return Promise.resolve(note);
    },
    deleteOwned(ownerId, noteId) {
      const index = notes.findIndex((note) => note.id === noteId && note.ownerId === ownerId);
      if (index === -1) return Promise.resolve(false);
      notes.splice(index, 1);
      return Promise.resolve(true);
    },
  };

  const auditRepository: AuditRepository = {
    record(event) {
      auditEvents.push(event);
      return Promise.resolve();
    },
  };

  // No real transaction: rollback behaviour is covered by the Postgres integration tests.
  const unitOfWork: UnitOfWork = {
    run: (work) => work({ notes: notesRepository, audit: auditRepository }),
  };

  return {
    users: usersRepository,
    unitOfWork,
    allUsers: () => [...users.values()],
    allNotes: () => [...notes],
    auditEvents,
  };
}

export type InMemoryStore = ReturnType<typeof createInMemoryStore>;
```

```ts
  requestId: string;

    create: (actor, input) =>

          entityId: noteId,
```

```ts
import express, { type Express } from 'express';
import helmet from 'helmet';
import { pinoHttp } from 'pino-http';
import { authenticate } from './auth/authenticate.js';
import type { TokenVerifier } from './auth/token-verifier.js';
import { healthRouter } from './health/health-routes.js';
import { errorHandler, notFound } from './http/error-handler.js';
import { genReqId } from './http/request-id.js';
import type { Logger } from './logger.js';
import { notesRouter } from './notes/notes-routes.js';
import type { NotesService } from './notes/notes-service.js';
import { meRouter } from './users/me-routes.js';
import type { UsersRepository } from './users/user.js';

export interface AppDependencies {
  version: string;
  requiredScope: string;
  logger: Logger;
  verifier: TokenVerifier;
  users: UsersRepository;
  notes: NotesService;
  checkDatabase: () => Promise<void>;
}

/** Builds the Express app from its dependencies. No I/O happens here, so tests can inject fakes. */
export function createApp(deps: AppDependencies): Express {
  const app = express();
  app.disable('x-powered-by');
  app.use(pinoHttp({ logger: deps.logger, genReqId }));
  app.use(helmet());
  app.use(express.json({ limit: '100kb' }));

  app.use(
    '/api/health',
    healthRouter({ version: deps.version, checkDatabase: deps.checkDatabase }),
  );

  const signedIn = authenticate({
    verifier: deps.verifier,
    requiredScope: deps.requiredScope,
    users: deps.users,
  });
  app.use('/api/me', signedIn, meRouter());
  app.use('/api/notes', signedIn, notesRouter(deps.notes));

  app.use(notFound);
  app.use(errorHandler);
  return app;
}
```

```ts
import { escapeIdentifier, type PoolClient } from 'pg';

/** Postgres role names Atlas will grant to: letters, digits, `_` and `-`, at most 63 bytes. */
export const ROLE_NAME = /^[A-Za-z0-9_-]{1,63}$/;

type Privilege = 'SELECT' | 'INSERT' | 'UPDATE' | 'DELETE';

/**
 * What the API's runtime role may do, table by table (spec §8.5).
 * There are no default privileges: a table missing here is unreachable by the API, and an
 * integration test fails if this list and the tables in schema `app` ever disagree.
 */
export const APP_TABLE_GRANTS = {
  users: ['SELECT', 'INSERT', 'UPDATE'],
  notes: ['SELECT', 'INSERT', 'UPDATE', 'DELETE'],
  audit_events: ['SELECT', 'INSERT'], // append-only: no UPDATE or DELETE
} as const satisfies Record<string, readonly Privilege[]>;

export function grantStatements(role: string): string[] {
  if (!ROLE_NAME.test(role)) throw new Error(`Unsafe database role name: ${role}`);
  const grantee = escapeIdentifier(role);
  return [
    `GRANT USAGE ON SCHEMA app TO ${grantee}`,
    `REVOKE ALL ON ALL TABLES IN SCHEMA app FROM ${grantee}`,
    ...Object.entries(APP_TABLE_GRANTS).map(
      ([table, privileges]) => `GRANT ${privileges.join(', ')} ON app.${table} TO ${grantee}`,
    ),
  ];
}

/** Re-applies the allowlist in one transaction: drift is corrected, with no window without privileges. */
export async function applyGrants(client: PoolClient, role: string): Promise<void> {
  const statements = grantStatements(role);
  await client.query('BEGIN');
  try {
    for (const statement of statements) await client.query(statement);
    await client.query('COMMIT');
  } catch (err) {
    await client.query('ROLLBACK');
    throw err;
  }
}
```

```ts
import { drizzle } from 'drizzle-orm/node-postgres';
import { migrate } from 'drizzle-orm/node-postgres/migrator';
import type { Pool, PoolClient } from 'pg';
import type { Logger } from '../logger.js';
import { applyGrants } from './grants.js';

/** Arbitrary but fixed: every migrator instance contends for the same lock. */
const MIGRATION_LOCK_KEY = 727_001;

export interface MigrationJobOptions {
  migrationsFolder: string;
  /** The runtime role to grant to: `atlas_app` locally, `id-atlas-api-{env}` in Azure. */
  appRole: string;
  /** Azure only: the runtime identity's object id, used to create its Entra-backed role. */
  appPrincipalId?: string;
  logger: Logger;
}

/** Spec §8.5: lock → migrate → (Azure) ensure runtime role → grants. Safe to run concurrently. */
export async function runMigrationJob(pool: Pool, options: MigrationJobOptions): Promise<void> {
  const client = await pool.connect();
  try {
    await client.query('SELECT pg_advisory_lock($1)', [MIGRATION_LOCK_KEY]);
    try {
      options.logger.info('applying migrations');
      await migrate(drizzle({ client }), {
        migrationsFolder: options.migrationsFolder,
        migrationsSchema: 'drizzle',
      });
      if (options.appPrincipalId) {
        await ensureEntraRole(client, options.appRole, options.appPrincipalId);
      }
      await applyGrants(client, options.appRole);
      options.logger.info({ appRole: options.appRole }, 'migrations and grants applied');
    } finally {
      await client.query('SELECT pg_advisory_unlock($1)', [MIGRATION_LOCK_KEY]);
    }
  } finally {
    client.release();
  }
}

/** Creates a Postgres role bound to an Entra identity. Exists only on Azure Database for PostgreSQL. */
async function ensureEntraRole(
  client: PoolClient,
  role: string,
  principalId: string,
): Promise<void> {
  const existing = await client.query('SELECT 1 FROM pg_roles WHERE rolname = $1', [role]);
  if (existing.rowCount === 0) {
    await client.query(
      "SELECT * FROM pgaadauth_create_principal_with_oid($1, $2, 'service', false, false)",
      [role, principalId],
    );
  }
}
```

```ts
import { and, eq, sql } from 'drizzle-orm';
import type { Executor } from '../db/client.js';
import { users } from '../db/schema.js';
import type { User, UserIdentity, UsersRepository } from './user.js';

export function createPgUsersRepository(db: Executor): UsersRepository {
  return {
    async upsertFromIdentity(identity) {
      const [upserted] = await db
        .insert(users)
        .values({ ...identity, lastSeenAt: sql`now()` })
        .onConflictDoUpdate({
          target: [users.entraTenantId, users.entraObjectId],
          set: {
            email: sql`excluded.email`,
            displayName: sql`excluded.display_name`,
            lastSeenAt: sql`now()`,
            updatedAt: sql`now()`,
          },
          // This runs on every request: skip the write unless something changed or
          // last_seen_at is more than 5 minutes old (spec §8.2).
          setWhere: sql`${users.lastSeenAt} < now() - interval '5 minutes'
            OR ${users.email} IS DISTINCT FROM excluded.email
            OR ${users.displayName} IS DISTINCT FROM excluded.display_name`,
        })
        .returning();
      return toUser(upserted ?? (await findByIdentity(db, identity)));
    },
  };
}

async function findByIdentity(
  db: Executor,
  identity: UserIdentity,
): Promise<typeof users.$inferSelect> {
  const [row] = await db
    .select()
    .from(users)
    .where(
      and(
        eq(users.entraTenantId, identity.entraTenantId),
        eq(users.entraObjectId, identity.entraObjectId),
      ),
    );
  if (!row) throw new Error('User row missing right after upsert');
  return row;
}

function toUser(row: typeof users.$inferSelect): User {
  return {
    id: row.id,
    entraTenantId: row.entraTenantId,
    entraObjectId: row.entraObjectId,
    email: row.email,
    displayName: row.displayName,
  };
}
```

```ts
import { and, desc, eq } from 'drizzle-orm';
import type { Executor } from '../db/client.js';
import { notes } from '../db/schema.js';
import type { NotesRepository } from './notes-repository.js';

export function createPgNotesRepository(db: Executor): NotesRepository {
  return {
    async listByOwner(ownerId) {
      return db
        .select()
        .from(notes)
        .where(eq(notes.ownerId, ownerId))
        .orderBy(desc(notes.createdAt), desc(notes.id));
    },

    async create(ownerId, input) {
      const [row] = await db
        .insert(notes)
        .values({ ownerId, title: input.title, body: input.body })
        .returning();
      if (!row) throw new Error('Insert into app.notes returned no row');
      return row;
    },

    async deleteOwned(ownerId, noteId) {
      // Ownership is part of the WHERE clause, so it can't be forgotten by a caller.
      const deleted = await db
        .delete(notes)
        .where(and(eq(notes.id, noteId), eq(notes.ownerId, ownerId)))
        .returning({ id: notes.id });
      return deleted.length > 0;
    },
  };
}
```

```ts
export default async function setup(project: TestProject): Promise<() => Promise<void>> {
  container = await new PostgreSqlContainer('postgres:17-alpine').withDatabase('atlas').start();
  const adminUrl = container.getConnectionUri();

  const appPassword = randomUUID();

    await admin.query(`GRANT CONNECT ON DATABASE atlas TO ${APP_ROLE}`);
  } finally {
    await admin.end();
  }

  const migratorUrl = withCredentials(adminUrl, 'atlas_migrator', migratorPassword);
  const appUrl = withCredentials(adminUrl, APP_ROLE, appPassword);

  const migrator = new Pool({ connectionString: migratorUrl });

    await runMigrationJob(migrator, {
      migrationsFolder: MIGRATIONS_FOLDER,
      appRole: APP_ROLE,
      logger: createLogger('silent'),
    });
  } finally {
    await migrator.end();
  }

  project.provide('postgres', { migratorUrl, appUrl });
  return async () => {
    await container?.stop();
  };
}

function withCredentials(url: string, user: string, password: string): string {
  const parsed = new URL(url);
  parsed.username = user;
  parsed.password = password;
  return parsed.toString();
```

```markdown
# 0005. Database identity: Entra-only auth, separate migrator and runtime roles, grants allowlist

- **Status:** Accepted
- **Date:** 2026-10-13

## Context

Database passwords are the most common secret in web apps: they get committed, logged, shared and never rotated. A single all-powerful database user also means that any SQL injection or bug in the API can drop tables or rewrite the audit trail.

## Decision

- **Azure:** password authentication is disabled. Each identity connects with a short-lived Entra token, fetched for every new connection (`poolConfig` in `apps/api/src/db/pool.ts`).
- **Two roles:**
  - The **migrator** (`id-atlas-migrator-{env}`, `atlas_migrator` locally) owns schema `app` and is the only role that can change it.
  - The **runtime role** (`id-atlas-api-{env}`, `atlas_app` locally) gets only the privileges listed in `APP_TABLE_GRANTS`. Notably, `app.audit_events` is `SELECT, INSERT` only, so the trail is append-only _in the database_.
- **No default privileges.** The migration job revokes and re-applies the allowlist every run, so drift is corrected. A new table is invisible to the API until someone adds it, deliberately, in a reviewed PR.
- **Local dev and Testcontainers create the same two roles,** so least-privilege bugs show up on a laptop, not in prod.

## Consequences

- No database secret exists anywhere: not in GitHub, not in Container Apps, not in `.env` for the cloud.
- Every new table needs one extra line in `grants.ts`, and the integration tests enforce it.
- Humans don't get standing access to UAT or prod databases (see `docs/runbooks/database-access.md`, M7).
```

- [ ] **Step 4: Create `docs/adr/0006-migrations-as-a-pre-deploy-job.md`**

```markdown
# 0006. Migrations run as a pre-deploy job, and must be expand-then-contract

- **Status:** Accepted
- **Date:** 2026-10-13

## Context

Running migrations when the API starts is simple, but it gives the runtime identity schema-changing rights. It also races when several replicas start together, and it turns a bad migration into a crash loop of the whole API.

## Decision

- Migrations run in a separate entrypoint, `apps/api/src/migrate.ts`. It's built into the same image as the API, so the code and the migrations always match, and in Azure it runs as a Container Apps Job (`caj-atlas-migrate-{env}`) _before_ the new API revision deploys (M5).
- The job takes a Postgres advisory lock, so two concurrent runs serialise. An integration test proves this.
- Because the old API version keeps running while the job migrates, every migration must be **backward compatible: expand, then contract.** Add the new column or table → ship → switch reads and writes → ship → drop the old one in a later release.

## Consequences

- A failed migration stops the deploy before any new code runs, and the previous revision keeps serving.
- Renames and drops take two releases. That's the price of zero-downtime deploys, and it's what large companies do.
- Locally, `npm run db:migrate -w @atlas/api` runs the same code path.
```
